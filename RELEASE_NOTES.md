# nc-notify 1.0.0

Трей-приложение для Astra Linux (Fly): напоминания о событиях Nextcloud и карточках Deck.

## Возможности
- Календарь Nextcloud по CalDAV: ближайшие события, повторяющиеся события (RRULE),
  группы «Сейчас / Сегодня / Завтра / Позже», прогресс идущих событий и обратный отсчёт.
- Карточки Nextcloud Deck: выбор досок, сроки, группы «Просрочено / Сегодня / Завтра /
  На неделе / Позже / Без срока», переход к карточке в браузере.
- Уведомления: fly-notifications и собственное окно; режимы «оба / только fly /
  только окно / тихо»; звук вкл/выкл; произвольные пороги «за N минут»; «Отложить 5 мин»;
  защита от повторных срабатываний.
- Несколько календарей, авто-синхронизация по таймеру, «Обновить сейчас» в трее.
- Пароль приложения хранится в связке ключей (gnome-keyring).
- Самоподписанный сертификат: доверие по отпечатку SHA-256 (pinning).
- Автозапуск при входе в систему, запуск свёрнутым, single-instance.
- Сквозная авторизация Kerberos/SPNEGO — экспериментально (в домене не проверена).

## Установка
    sudo apt install ./nc-notify_1.0.0_amd64.deb

Запуск: меню приложений «Nextcloud Notify» или команда `nc-notify`.
Первичная настройка: Настройки → Аккаунт (адрес сервера, логин, пароль приложения
Nextcloud) → «Найти календари»; вкладка Deck → «Найти доски».

Пароль приложения создаётся в Nextcloud: Настройки → Безопасность → Устройства и сессии.

## Полезные ключи
    nc-notify --version      версия
    nc-notify --minimized    запуск только в трей
    nc-notify --verbose      подробный лог в терминал
    nc-notify --curl-info    диагностика GSS-API/SPNEGO (для Kerberos)

## Известные ограничения
- Kerberos не протестирован в домене (проверка планируется).
- Цельнодневные события не уведомляются (отображаются в списке).
- Переопределения THISANDFUTURE в повторах не разворачиваются.

## Проверка целостности
